## 什么是认知扭曲

认知行为治疗（CBT）发现：当我们情绪强烈时，脑子里出现的"事实陈述"经常是**结论**，而不是**结论的根据**。

「认知扭曲」的概念来自 Aaron Beck 的认知疗法，David Burns 在《Feeling Good》（1980）中把它整理成 10 种常见类型，后来不同作者又陆续扩充。下面是一份常见类型的简表（分类与叫法在不同书里略有差异）：

| 扭曲 | 类型 | 通俗解释 |
|---|---|---|
| 全或无 | 黑白思维 | "要么全好，要么全坏" |
| 以偏概全 | 过度泛化 | "这次没做好 = 我永远做不好" |
| 心理过滤 | 选择性注意 | 只看到负面，忽略所有积极部分 |
| 否定正面 | 折扣正面 | "那次成功只是运气好" |
| 仓促结论 | 跳步 | "他没回消息 = 他讨厌我" |
| 放大或缩小 | 比例失真 | 把小错放大成灾难，把大成就缩小成"没什么" |
| 情绪化推理 | 感受当事实 | "我感觉自己失败 = 我就是失败的人" |
| "应该"陈述 | 苛刻规则 | "我应该/必须/不应该……" |
| 贴标签 | 以偏概全 | "我是个 loser" |
| 个人化 | 揽责 | "团队出问题是因为我" |
| 罪由归己 | 揽功反向 | "我做得好是运气，别人做得好是能力" |
| 公平谬误 | 比较陷阱 | "努力应该被立刻奖励" |

## 看到它的第一步：命名

下次情绪上来时，安静问一句："我刚才用到了哪一种？"

给念头起个名字，往往能帮你和它拉开一点距离——它是一种想法，不一定是事实。

## 一份练习

挑一条你最近常用的扭曲，写下：
- 这条触发的事件
- 当时你脑子里的"事实陈述"
- 现在你会怎么命名它
- 一条更平衡的替代陈述

坚持一段时间，你会越来越容易在当下认出它们。如果负面想法长期占据生活、影响睡眠或工作，请寻求专业帮助。
